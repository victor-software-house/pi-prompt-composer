# docs/

Repository documentation lives in this directory unless it is one of the root exceptions:

- `README.md`
- `AGENTS.md`
- `CHANGELOG.md`

## Scope

Use `docs/` for canonical project documents such as:

- `ROADMAP.md`
- `FEATURE-SET.md`

## Rules

- Keep canonical document filenames uppercase.
- Keep the structure flat unless a real subtree needs its own folder.
- Prefer one canonical document per topic.
- Link between docs instead of duplicating the same content.
- Keep documents concise and easy to scan.
